# 🏗️ ZÉDIA — Démonstration Commerciale Interactive (1m45)

> Démonstration commerciale interactive conçue pour les artisans et TPE du bâtiment.

## 🎯 Objectif
Permettre à un artisan qui découvre ZÉDIA pour la première fois de comprendre en moins de 2 minutes :
1. Le problème des devis laissés sans suite le soir après les chantiers.
2. La solution ZÉDIA (relances automatiques au nom de l'atelier, arrêt 100% automatique, ventilation HT/TVA).
3. Le fonctionnement réel à travers les 5 étapes concrètes de l'espace artisan.
4. Les bénéfices directs sur son quotidien.
5. L'offre Découverte gratuite (jusqu'à 3 devis actifs sans carte bancaire) avec lien vers [https://zedia-devis.ai.studio](https://zedia-devis.ai.studio).

## 🚀 Démarrage Rapide

### Prérequis
- Node.js (version 18 ou supérieure)
- npm ou bun

### Installation
```bash
npm install
```

### Lancer en développement
```bash
npm run dev
```

### Compiler pour la production
```bash
npm run build
```
Les fichiers prêts pour le déploiement ou l'envoi par e-mail se trouvent dans le dossier `dist/`.

### Prévisualiser le build de production
```bash
npm run preview
```
Puis ouvrez votre navigateur sur `http://localhost:4173`.
